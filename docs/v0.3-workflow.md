# Version 0.3 workflow

## 1. Job intake

Capture the company, title, source URL, source name, full description, retrieval time, displayed posting text, and published timestamp when the source exposes one. Missing required fields or an invalid source URL stops intake.

## 2. Requirement extraction

The local extractor separates explicit responsibilities, required qualifications, and preferred qualifications from headed job-description sections. Every extracted item starts as `REVIEW_REQUIRED` with an `unclear` match state. Human review confirms the text, category, non-negotiable status, and evidence links.

## 3. Recency assessment

When both publication and retrieval timestamps exist, the agent calculates age and compares it with the configured 72-hour window. Relative text such as “today” stays recorded as displayed text and receives `UNVERIFIED` status unless a source timestamp supports the claim.

## 4. Evidence matching and scoring

Confirmed requirements link to evidence IDs. The existing weighted scorer applies the 75 percent threshold and blocks roles with unmet non-negotiables or missing evidence records.

## 5. Résumé review

Qualified roles receive an evidence-locked tailoring plan. The final résumé requires approval. Employment facts, education, metrics, tools, portfolio results, and unsupported claims stay locked.

## 6. Contact research

Contact records preserve the person's identity, relationship to the role, public sources, email status, confidence, and verification result. `INFERRED_PATTERN` records require at least two supporting sources and never permit automatic outreach.

## 7. Approval queue

Requirement review, evidence confirmation, résumé approval, contact verification, outreach, sensitive application answers, and submission each receive a separate approval item. Every item starts as `PENDING`.

## 8. Tracking

The workbook contains Overview, Job Discovery, Qualified Roles, Contacts, Approvals, and Configuration tabs. Google Sheets is the primary destination. The local workbook serves as the import-ready template until an authenticated Google Drive connection is available.
