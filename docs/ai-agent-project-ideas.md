# AI agent projects for Farrah's GitHub

## Recommended sequence

### 1. Application Buddy

Builds job discovery, evidence-based fit scoring, application preparation, tracking, and approval controls. Demonstrates agent architecture, structured data, evaluation, human review, and a real customer workflow.

### 2. Customer Onboarding Risk Agent

Reads a fictional implementation plan, identifies missing dependencies, assigns risk levels, proposes next actions, and prepares stakeholder updates. Demonstrates implementation management and proactive Customer Success.

### 3. Voice of Customer Synthesis Agent

Processes a synthetic set of support tickets, interview notes, and survey comments. Groups themes, links claims to source records, identifies product friction, and prepares a product feedback brief.

### 4. Customer Health and Adoption Agent

Analyzes synthetic product-usage, support, training, and stakeholder-engagement data. Produces explainable health signals and recommended playbooks without claiming certainty.

### 5. Implementation Handoff Agent

Transforms a fictional sales handoff into an implementation brief, open-question list, stakeholder map, milestone plan, risk register, and kickoff agenda.

### 6. Escalation Triage Agent

Classifies fictional customer issues by severity, technical domain, business impact, urgency, and required owner. Includes human escalation and traceable decisions.

### 7. Executive Business Review Agent

Uses synthetic account data to prepare an executive review with adoption, outcomes, risks, decisions, and next-quarter recommendations. Every statement links to a source record.

## Portfolio value

Together, these repositories show discovery, implementation, adoption, support, escalation, executive communication, evaluation, and evidence traceability. Each project should include a README, architecture diagram, sample data, setup steps, tests, evaluation results, screenshots, limitations, and a short demo.
