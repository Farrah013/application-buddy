# ATS-first résumé standard

## Priority order

1. Factual accuracy and evidence approval
2. ATS-readable structure and text extraction
3. Job alignment and supported keywords
4. Human readability
5. Visual refinement

Appearance review starts only after the ATS content and document gates pass.

## Required structure

- One-column document flow
- Candidate name and contact details in the document body, including the exact full LinkedIn URL as selectable text
- Standard section labels
- Conventional employer, title, location, and date order
- Plain paragraphs and real bullets
- Selectable text
- Consistent month-and-year dates
- DOCX as the primary application file, with PDF produced when requested or accepted

## Prohibited structure

- Text boxes
- Multi-column layouts
- Content stored only in headers or footers
- Tables used for résumé layout
- Images, icons, skill bars, charts, logos, and decorative graphics
- Important information conveyed only through color
- Keyword stuffing
- Hidden text
- Unsupported acronyms, qualifications, metrics, or tools

## Appearance rules after ATS approval

- Use Arial with restrained sizing and spacing
- Preserve one-column reading order
- Use dark text with one restrained accent color
- Keep headings distinct without decorative elements
- Use spacing, weight, and alignment for hierarchy
- Reject any reference-image feature that introduces columns, tables, text boxes, icons, graphics, or nonstandard reading order

## Reference-image workflow

1. Audit the reference image for typography, spacing, hierarchy, alignment, section order, color, and density.
2. Classify every feature as ATS-safe, conditional, or rejected.
3. Adopt ATS-safe features only.
4. Rebuild the résumé with paragraphs and styles rather than copying the image as a background or layout object.
5. Run text extraction and structural checks.
6. Perform visual rendering and page review only after the ATS gate passes.
