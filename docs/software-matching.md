# Software matching rules

## Baseline

The baseline contains software Farrah reported using or having some experience with. No proficiency level, years of use, certification, administrator status, or professional depth is inferred.

## Match states

- `EXACT_SELF_REPORTED`: The required software appears in the baseline.
- `SIMILAR_FUNCTIONAL_CATEGORY`: A baseline tool serves a similar function. This receives partial alignment, not an exact match.
- `USER_CONFIRMATION_REQUIRED`: The job lists software outside the baseline. Ask Farrah whether she has used it before scoring.
- `NOT_MET_CONFIRMED`: Farrah confirms no experience and no acceptable equivalent applies.

## Application behavior

An unfamiliar software name does not automatically reject a role or stop application preparation. Application Buddy first asks Farrah about direct or related experience.

When a job treats one named product as a mandatory requirement, similar software does not satisfy the non-negotiable gate without review.

When a job accepts comparable platforms, a similar functional category receives partial credit and the evidence record names the exact tool Farrah used.

Application questions about years, proficiency, administration, implementation, or certification always require Farrah's confirmation.

## Resume behavior

The resume lists only tools from the approved baseline or later confirmed additions. The builder does not replace a tool name with another product name for keyword matching.
