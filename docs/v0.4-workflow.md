# Version 0.4 workflow

## Résumé source record

`data/resume-source.json` stores confirmed employers, titles, dates, locations, bounded bullet language, education, and source status. It excludes planned certifications and unsupported numeric claims.

## Review draft

The résumé engine ranks source-verified bullets against reviewed job requirements. Every generated résumé begins as `REVIEW_DRAFT` with `final_use_allowed: false`. Summary, bullet selection, skills, portfolio claims, and final document each require approval.

## Portfolio boundary

Skills from `user_provided_unverified` portfolio records stay outside the generated résumé. Approved `portfolio_evidence` records become eligible after the project audit confirms artifacts and claims.

## Application answers

Answers use selected evidence IDs. Missing IDs block generation. Salary, compensation, work authorization, visa, disability, veteran, demographic, signature, and relocation questions require direct user input.

## Change report

The change report compares the master source with the tailored draft. Summary revisions and skill filtering receive separate review entries. No tailored document becomes final without approval.

## Document rendering

The DOCX renderer produces a one-column ATS-readable review copy with a visible submission block. The review fixture is never an approved application document.
